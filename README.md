# PDF Object Streams Disabler

A single-file web app that runs `qpdf --object-streams=disable input.pdf output.pdf` entirely in your browser. Drop in a PDF, get a PDF back with every object stored separately. Nothing is uploaded.

## Features

- Runs the real [qpdf](https://github.com/qpdf/qpdf), compiled to WebAssembly
- 100% client-side: files never leave your device
- One self-contained HTML file, no server and no build step needed to use it
- Works offline once the page is loaded
- Drag-and-drop or file picker, light and dark mode, mobile friendly
- Shows input and output size, and qpdf's log output when there are warnings

## Usage

1. Open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari), or host it on any static site host.
2. Drop a PDF onto the page, or click to choose one.
3. Click **Download** to save `<name>-no-objstm.pdf`.

## What the command does

Many PDFs pack small objects into compressed containers called object streams. `--object-streams=disable` rewrites the file so every object is stored on its own. The output is usually slightly larger, but it is easier to read for older or simpler PDF tools. Page content is unchanged.

## How it works

1. The page embeds the qpdf WebAssembly binary as base64, plus the small JavaScript loader from [`@neslinesli93/qpdf-wasm`](https://www.npmjs.com/package/@neslinesli93/qpdf-wasm) (v0.3.0).
2. On load, the binary is decoded and compiled by the browser.
3. When you choose a file, it is written to qpdf's in-memory virtual filesystem as `/input.pdf`.
4. The app calls qpdf's `main` with `--object-streams=disable /input.pdf /output.pdf`.
5. `/output.pdf` is read back and offered as a download through a Blob URL.

The stock loader fetches `qpdf.wasm` from a URL. This project patches it to use the embedded bytes instead, so the page needs no network requests.

Exit codes: `0` success, `3` success with warnings (output is still produced), `2` failure.

## Limitations

- Password-protected PDFs are not supported, because the command has no password argument.
- Very large PDFs are limited by your browser's available memory.

## Building from source

The HTML file is generated by inlining the loader and the base64 wasm into a template.

```bash
npm install @neslinesli93/qpdf-wasm
```

Then, with a script of your choice:

1. Read `node_modules/@neslinesli93/qpdf-wasm/dist/qpdf.js` and `qpdf.wasm`.
2. Patch the loader so `Da(a)` returns the embedded bytes (for example `window.__WASM`) and skip the streaming-fetch branch in `Fa(a)`.
3. Insert the patched loader and the base64 wasm into the HTML template.
